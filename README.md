# AI 销售 Skill 作品集

这是一组面向 To B 销售场景的可复用 Skill，围绕客户研究、客户筛选和拜访复盘三个关键动作。三个 Skill 都采用可解释输出，强调证据来源、待验证假设和人工可修正性。

## 1. Account Battle Card Skill｜客户作战档案

**解决什么问题：** 把零散的公司资料、新闻、融资、招聘和 CRM 记录整理成结构化客户档案。

**输出什么：** 拜访准备、邮件草稿和演示邀约所需的上下文。

**仓库链接：** [yicanyang142-del/account-battle-card-skill](https://github.com/yicanyang142-del/account-battle-card-skill)

## 2. Sales Visit Review Skill｜拜访复盘

**解决什么问题：** 拜访后需要人工复盘客户痛点、预算、决策链和顾虑。

**输出什么：** 拜访摘要、客户反馈、后续待办、策略调整和沟通改进建议。

**仓库链接：** [yicanyang142-del/sales-visit-review-skill](https://github.com/yicanyang142-del/sales-visit-review-skill)

## 3. B2B Prospect Screener｜客户筛选

**解决什么问题：** 联系客户前需要判断企业是否值得优先跟进。

**输出什么：** 高潜客户清单、评分明细、证据来源和 Excel 报告。

**仓库链接：** [yicanyang142-del/b2b-prospect-screener](https://github.com/yicanyang142-del/b2b-prospect-screener)

## 共同设计原则

- 区分事实、推断和待验证假设
- 每条关键判断保留证据或来源
- 不编造客户信息、联系人或商业承诺
- 输出结构化 JSON，方便接入 CRM 或其他工作流
- 不做爬虫，不接真实企业数据源，仅使用 Mock 数据验证逻辑
